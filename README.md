# The Architect's Interface

Free blueprints from the lessons on [The Architect's Interface](https://www.youtube.com/@TheArchitectsInterface), with Ember.

A blueprint is a plain-language instruction set you paste into any AI chat to change how it behaves. You don't need any code. Copy one, paste it in, and watch what changes.

## Blueprints

| Lesson | Blueprint | What it does |
|---|---|---|
| Ep01 · X-Ray Mode | [x-ray-mode-v1.2.txt](blueprints/ep01-x-ray-mode/x-ray-mode-v1.2.txt) | Makes your AI show its work: where each claim came from, which tools actually ran, and what it assumed without telling you. |

More are added as new lessons come out.

## How to use one

1. Open the blueprint file and copy all of it.
2. Paste it into a new chat on any AI (Claude, ChatGPT, Gemini and others).
3. Ask your questions as usual. The blueprint explains how to turn it on and off.

## Notes

These are early, open research. Each blueprint was tested on free plans, with one run per platform. Results vary by model and can change over time.
